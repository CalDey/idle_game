# 音频来源与许可

本游戏的全部音乐与音效都由 `js/audio.js` 用浏览器 Web Audio API **实时合成**，仓库内没有任何音频文件，也没有引用第三方采样、音色库或付费素材。

| 名称 | 用途 | 合成方式 | 来源 | 许可 |
| --- | --- | --- | --- | --- |
| 吐纳 | 点击修行页立绘 | 带通滤波噪声（气声）+ 上滑正弦 | 原创代码（js/audio.js `SFX.tuna`） | 随本仓库发布；作者另以 CC0 1.0 放弃该合成音色的权利 |
| 突破成功 | 境界提升 | D 小调五声上行拨弦 + 钟声泛音 | 原创代码（`SFX.breakthrough`） | 同上 |
| Boss 现身 | Boss 关开战 | 下滑正弦低鼓 + 窄带噪声闷锣 + 低埙 | 原创代码（`SFX.boss`） | 同上 |
| 背景音乐 | 循环氛围 | D2 低音持续 + 随机五声古琴式拨弦 + 偶发埙式长音 | 原创代码（`scheduleMusic`） | 同上 |

规则：设置里的「背景音乐」「音效」两个开关默认关闭，偏好存于 localStorage `xiuxian_audio`（不进存档）；只有在玩家点击或按键之后才会创建 AudioContext，页面切到后台时暂停。
