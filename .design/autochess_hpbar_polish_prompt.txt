【任务】把自走棋头顶血条好好设计一遍，并修掉 Boss 框挡血条。

问题：
A. “多一点点格”：现在 maxHp/step 经常是 5.3 这种小数，repeating-linear-gradient 按百分比画刻度，最后留下一根细细的半截格，看起来很业余。
B. Boss 头像/红框仍会挡住血条（自己的或旁边/下面棋子的）。Boss 头像放大后向上溢出，正好盖到头顶血条区域。

要求：

1) 刻度必须是整数整格，绝不出现半截格
- 先用现有 1/2/5×10^n 逻辑选出参考 step，再令
  segments = clamp(round(maxHp / step), 3, 8)
  对 Boss 允许到 10。
- 视觉上血条被均分成恰好 segments 格，每格宽度 = 100/segments %（CSS 变量 --hp-step-pct）。
- 刻度线画在整格边界上（第 1..segments-1 条），最后一格是完整宽度，禁止残留细缝/半格。
- 血量填充仍按 hp/maxHp 的真实比例（可以停在某格中间，那是当前血量，不是“半截格子”）。
- 同一阵营尽量共用同一个 segments 值（用该侧最低 maxHp 算出 segments 后，侧内统一）；Boss 可单独用更大的 segments。
- 每 5 格一条稍粗刻度可保留。

2) 血条外观重新打磨（仍在头顶）
- 容器：宽 = 头像直径 + 4px，高 = 血条 6px + 间隔 1px + 怒气 3px；黑底 #07070c；外描边 box-shadow: 0 0 0 1px #000；圆角 2px。
- 血条彩色区高度 6px；我方 #3ecf7a → #9bffc2，敌方 #e03a3a → #ff7a7a；格子之间用 1px 纯黑竖线隔开（刻度）。
- 怒气条高度 3px，金色 #e0a72e → #ffe08a；满怒轻微闪烁，无外发光。
- 保留白色延迟残血 lag 层。
- 血条组底边距圆环顶 3px。

3) Boss 框绝不能挡任何血条
- Boss 头像放大时只允许向左右和下方溢出，禁止向上溢出进入自己的血条区域（例如 .unit-avatar-wrap 设 transform-origin: center top；或放大时用 translateY 把溢出偏向下方；或给 .unit-body 顶部为血条预留固定高度且 avatar 区域 overflow 在顶边裁切）。
- 自己的 .unit-bars 必须完整露在 Boss 头像/红框之上（同单位内 bars z-index 明显高于 avatar-wrap）。
- Boss 相对同行/下一行：保持现有“越靠下 z 越高”规则；Boss 的 +1 加成不能让它盖住下一行棋子的血条。
- Boss 标签继续在头像左下，不压血条。

4) 不要改坏：头像图、品质边框、拖动、放大招、战斗逻辑、行 z-index 方向（下层更高）。
5) index.html 中改过文件的 ?v= 各 +1。
