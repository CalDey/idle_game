【任务】自走棋棋子的头顶血条不能被任何头像盖住。

问题（390×844 实测）：上下相邻时，下一行棋子的圆形头像会盖住上一行棋子的头顶血条；战斗中棋子冲刺/位移时也一样。根因是每个 .board-unit 自己有 z-index，后绘制的棋子整层盖过先绘制的棋子，血条虽然在本单位内 z-index 较高，但挡不住别的单位的头像。

要求：
1. 按棋盘行号给棋子分层：越靠上的行 z-index 越高（例如 z = 10 + (7 - r)，r 是 0..7 的行号），这样上一行的“血条 + 头像”整体压在下一行头像之上，血条就不会被盖住。Boss 在同规则基础上再 +2。拖动中的棋子保持最高（现有 .is-dragging 的 z-index: 20 再调高到 30）。大招就绪棋子可以略高，但不要超过拖动。
2. 实现方式任选其一（选更干净的）：
   - 在 js/stage-ui.js 放置/更新棋子位置时，根据 unit.r（或当前格子行）设置 el.style.zIndex；战斗中行变化时同步更新。
   - 或用 CSS 变量 --unit-row 配合选择器。
3. 同一棋子内部：.unit-bars 的 z-index 必须高于本单位的 .unit-avatar-wrap，确保血条永远在自己头像之上。
4. 不要把血条从棋子里拆出去做成独立层（保持现有 DOM 结构）。
5. 不要改坏：头像图片、品质边框、标签、拖动、放大招、战斗逻辑、血条样式。
6. index.html 中改过文件的 ?v= 各 +1。
7. 不要运行终端命令，不要 git 操作。
