当前：血条和怒气条在圆形头像下方。改成：
1. 位置：血条组放在圆形头像正上方，底边距圆环顶部 2px，水平居中；头像整体在格子里下移，让“血条组 + 头像”整体在本格内居中，不超出本格、不和上下格棋子重叠。头像直径改为 calc(min(var(--cell-w), var(--cell-h)) - 13px)（390×844 下约 44px，比现在更大），血条组(约 8px)+2px 间隙+头像 必须在 cellH 内。Boss 同理放在 Boss 头像正上方，宽度更宽。
2. 样式：
   - 血条组宽度 = 头像直径 + 4px。外层黑色底 #0b0b0f，1px 黑色外描边（box-shadow: 0 0 0 1px #000，不占高度），圆角 1px。
   - 血条彩色区高度 5px；下方 1px 黑间隔，再接怒气条彩色区高度 2px。
   - 我方血条绿色 #4fd18b→#8ef0b0，敌方红色 #d13a3a→#ff7373；怒气条金色 #e0a72e→#ffe08a；保留白色“延迟残血” lag 层。
   - 分段刻度：血条上每隔固定血量画一条 1px 黑色竖线（用 repeating-linear-gradient 叠在血条上，或 JS 计算刻度间隔并设置 CSS 变量）。刻度间隔按该单位最大生命值自动取“整数好看值”（1/2/5×10^n 中，使刻度数在 3~8 之间），同一场战斗内同阵营单位用同一个间隔，这样血越厚格子越多，一眼看出谁更肉。每 5 格可以画一条稍粗(1.5px)的刻度。

3. 主角“主”角标、“Boss”标签、大招标签不能和头顶血条重叠：主角角标放到头像左下角；Boss 标签放在血条左侧或头像左下角，小字号；“大招”就绪标签放在头像下沿居中。
