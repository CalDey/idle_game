【洞府页两处小修正】只改代码，不运行终端命令，不做 git 操作。

1. js/game.js 的 layoutHomeStage()：当前算法在容器比底图更“瘦高”时（W/H < r），舞台宽度等于 W、高度不足 H，地图上下会露出模糊背景条（例如 390×844 下底部有约 9px 的灰条）。请把尺寸计算改成：
   - coverScale = max(W / 1080, H / 1935)，舞台按 cover 计算：stageW = 1080*coverScale，stageH = 1935*coverScale。
   - 裁剪上限：横向每边最多裁掉 stageW 的 6%，纵向每边最多裁掉 stageH 的 10%。若 cover 结果超过上限，就把 scale 降到刚好满足上限（scale = min(coverScale, W/(1080*0.88), H/(1935*0.8))），剩余空白再用已有的模糊背景填充。
   - 舞台在容器内水平、垂直居中（left/top 可为负）。
   其他逻辑不变。

2. 洞府升级弹窗（#home-upgrade-modal）中，未解锁的建筑行现在仍显示 ×1/×10/最大 按钮。按需求，未解锁行应整行置灰，只显示“需突破至【xx】解锁”，不显示这三个按钮（隐藏，而不仅是禁用）。建筑解锁后按钮正常显示。
