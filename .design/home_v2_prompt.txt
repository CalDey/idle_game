二、state.js 存档
1. createDefaultState() 新增 home: { maxTier: {每个 DONGFU_LIST id: 0}, bgMaxTier: 0 }。
2. mergeSave(def, saved) 中合并：home: { ...def.home, ...(saved.home||{}), maxTier: { ...def.home.maxTier, ...((saved.home && saved.home.maxTier)||{}) } }。旧存档没有 home 或 home 结构不同（之前废弃版本写过 state.home）都要正常运行，不要改 version。
3. performReincarnation()：在 fresh = createDefaultState() 之前深拷贝 state.home 为 keepHome，之后令 fresh.home = keepHome。建筑等级照旧重置，外观档位不重置。
4. 新增并导出 getHomeDisplayTier(id) = max(homeBuildingTier(当前 lv), state.home.maxTier[id])；getHomeBgDisplayTier() = max(homeBgTier(总等级), state.home.bgMaxTier)。
5. 新增并导出 getOfflineCapSeconds()：基础 GameConfig.OFFLINE_CAP_SECONDS（12h），加 floor(灵泉眼 lv / 20) × 0.5h，最多 15h。把 state.js loadGame 里三处 window.GameConfig.OFFLINE_CAP_SECONDS（约 334、340、357 行）换成 getOfflineCapSeconds()。stage-ui.js 里两处 `window.GameConfig.OFFLINE_CAP_SECONDS || 12 * 3600`（约 276、589 行）改为优先用 window.GameState.getOfflineCapSeconds()。
6. getQiPerSec()：return 的乘积中加一项 (1 + 0.01 * Math.floor(聚灵石阵 lv / 10))。
7. 导出公共升级函数 buyDongfu(id, n)，n 为 1、10 或 Infinity。逐级用现有 getDongfuCost(item) 计算，灵石足够且已解锁（realmIndex >= unlockRealmIndex）时扣灵石、lv+1，返回实际升级数。
